# ✅ User Stories Completed

### 👤 Customer
- Browse restaurant menu
- Place food orders
- Track order status in real time

- View live kitchen queue

# 🎯 Problem Statement

Restaurants often struggle with delayed communication between customers, kitchen staff, and managers, leading to slower service and order confusion. SmartServe provides a centralized, AI-assisted, real-time platform that enables seamless order management, live kitchen updates, and efficient restaurant operations while improving the overall customer experience.
